# conthetron.com

Personal website and blog for [Connor Smith](https://www.conthetron.com), built with [Hugo](https://gohugo.io/).

Design based on the [Hyde](https://github.com/poole/hyde) theme by [@mdo](https://github.com/mdo).

## Local Development

```bash
hugo server -D
```

Then open [http://localhost:1313](http://localhost:1313).

## Deployment

Pushing to `master` triggers the GitHub Actions workflow which builds and deploys to GitHub Pages.
